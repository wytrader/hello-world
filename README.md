# hello-world

## 项目说明

这个仓库当前提供了一个 Python 排序示例程序：`sort_algorithm.py`。

它使用 **归并排序（Merge Sort）** 对整数列表进行升序排序，并提供简单命令行交互。

## 功能

- `merge_sort(nums)`：返回新的升序列表，不修改原列表。
- 交互式输入：读取一行“空格分隔整数”。
- 输出排序结果。

## 运行方式

```bash
python3 sort_algorithm.py
```

输入示例：

```text
3 1 2 9 5
```

输出示例：

```text
排序结果： [1, 2, 3, 5, 9]
```

## 算法复杂度

- 时间复杂度：`O(n log n)`
- 空间复杂度：`O(n)`
- 稳定性：稳定排序

## 代码结构

- `sort_algorithm.py`
  - `merge_sort`：递归拆分与排序
  - `_merge`：合并两个有序子数组
  - `main`：命令行入口

## 注意事项

- 输入必须是整数且空格分隔。
- 空输入会输出 `[]`。
- 非整数字符会触发 `ValueError`。
